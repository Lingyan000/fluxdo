# 士多与服务卡片体验核对

商城接口、数据映射和买家流程由独立士多插件维护，宿主提供页面组件、受控网络、凭证与收银台。

| 使用流程 | 核对范围 | 落点 |
| --- | --- | --- |
| 服务入口 | 整张卡片进入默认页，卡片下方可定义统计等内容，菜单保持独立 | 清单 `card.page`、通用统计组件、独立插件 |
| 页面外壳 | 标题不重复服务名与第三方标签；权限从插件管理进入，使用时仍可申请 | 宿主页面 |
| 商品列表与店铺 | 分类、搜索、推荐排序和分页；封面、折扣、测试/推广标识、卖家头像；店铺资料与销量独立于商品列表 | 固定工具区、网格和金额组件、士多插件 |
| 商品详情 | 图片查看、格式化说明、库存和限购条件；评分摘要、评论作者、已购标记及分页回复 | 受控图片与富文本组件、士多插件 |
| 下单 | 数量、核价、选券、金额变化确认、幂等恢复、自动打开订单 | 通用数量组件、士多插件 |
| 订单与售后 | 订单快照的原价、折后单价、券后金额，买卖双方、支付与发货时限、交付查看/复制；售后原因、卖家说明和处理记录 | 通用详情与时间线、士多插件 |
| 优惠券 | 适用范围、有效期、占用/使用订单、实际优惠、不可用原因 | 士多插件 |
| 账号与消息 | 登录头像、待办、近期订单、按需读取的消费分布；系统消息筛选、分页和显式已读，消息可跳转关联商品、券和订单 | 士多插件 |
| 收藏 | 收藏与不感兴趣的商品分别搜索、分页，显示收藏或隐藏时间，可恢复展示 | 士多插件 |
| 社区与补货 | 售罄发卡商品的补货订阅；评论回复、赞踩和有资格的删除；商品/评论举报、处理记录与文字补充 | 士多插件 |

敏感操作仅以模拟服务验证；不使用真实账号支付、退款或发布评论。界面检查覆盖小屏、大字、明暗主题、加载/空态/失败。公共组件同步开发中心、参数契约与独立 SDK。

「我的士多 → 求购洽谈」与消息页标题栏提供原生会话列表、历史消息、发送、已读同步和关联订单入口。数据来自网站使用的 `/api/shop/conversations/my`、`/buy-sessions/:id`、`/messages`、`/read`；消息以稳定 ID 合并，页面隐藏停止轮询，实时事件只更新可见会话或提示列表更新。发送失败保留草稿，结果未确认时重发需要确认；服务端 `canSendMessage` 决定输入区是否可用。

求购发布、创建新洽谈、调价和卖家后台继续由网站提供。这些涉及求购审核、卖家库存和履约写操作，不能复用买家建单协议推断。现有求购会话接口已核对公开前端的 `buyRequestService` 与 `MyBuyChats` 模块，卖家完整后台应作为独立业务扩展，不进入宿主框架。网页与插件凭证分区，网页可能需要自行登录，插件不会把令牌注入网页。公开查询可附带士多会话以取得用户有权看到的条目，返回 401 后可按游客重试一次。订单、收藏、私有消息没有匿名回退。

士多图片使用匿名图片出口。论坛头像模板按大小展开；士多支持的论坛头像路径走其公开头像代理。订单先取订单快照自带的封面，缺失时按商品标识合并查询商品详情。列表省略图片不等于商品详情没有图片。无法获得头像时显示昵称首字，确认无图的订单不保留空图片框。

从原安装来源更新插件可以保留状态与数据。宿主兼容性以插件清单 `requiredFeatures` 为准。

界面文案支持简体、台湾繁体、香港繁体和英文；切换语言保留已加载的数据，服务返回内容与用户输入保持原文。举报截图由宿主选择和预览，通过受控上传发往士多；每次提交保留操作号，不自动重试。举报核查不会替代退款流程。

「我的士多 → 消息提醒」分别控制后台检查和系统通知。首次启用仅记录当前消息基线，后续按新消息 ID 与服务端时间去重；同时更新商城导航角标。15 分钟是调度期望，系统可推迟执行，强制停止应用后不保证运行。退出士多、撤权或停用插件会停止对应任务；系统禁用通知时可继续同步角标。市场条目使用预览渠道，与 GitHub 预发布一致。


### 实时消息（2.3.0）

买家插件接入 `/api/shop/notifications/stream`，由通用 `eventStreams` 能力传输。实例共享连接，摘要更新未读统计，系统消息变更静默更新第一页；已分页的列表提示手动刷新。断线补查摘要和可见消息，隐藏暂停，失效会话停止重试；遵守服务端连接数限制的冷却提示。不把服务端消息当作付款成功依据，订单仍回查权威状态。

SDK 0.7.0 增加流接口、事件类型与应用内动态演示；不增加常驻权限按钮或新的通知授权弹层。没有用户账号实测，未执行付款、退款或标记已读。
