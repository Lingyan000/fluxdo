# 插件定时更新

入口：元宇宙 → 插件管理 → 菜单 → 插件自动更新；市场源页面也提供入口。

默认每天检查，可选关闭、每 6 小时、每天或每周。每个插件可单独排除；关闭总计划后，“立即检查”仍能查询和准备候选，但不会自动安装。单插件设置保存在宿主中，插件脚本不能修改。

## 来源与安装

只检查已启用市场源中、与原安装来源完全相同的插件 ID。不按名称匹配，也不从其他源接管同 ID 插件。文件安装和独立清单地址安装需要手动更新；从市场重新审阅安装后可以参与定时更新。

版本比较、宿主兼容性、HTTPS 下载、大小限制、SHA-256、清单身份、脚本和 RFW 校验复用市场安装流程。相同版本与旧版本不会覆盖。下载完成的包放在宿主独立更新库，安装前重新校验摘要和清单。

授权声明完全一致且 SDK API 版本相同的更新可自动安装；网络域名、权限、凭证范围、任务声明和链接接管等变化进入“需要确认”，由现有安装审阅页面处理。更新保留启用/停用状态、挂起原因、本地数据、服务凭证和用户的权限开关，不重新授予已关闭权限。

安装前及索引持久化后都核对原版本、来源、自动更新选择和使用状态。下载时发生卸载、换源、手动升级或关闭自动更新，迟到的结果不能重新安装。索引提交期间通过任务库的短租约暂停新任务领取，避免前后台交接运行旧代码。代码采用按摘要保存的独立文件；新索引提交失败或提交期间发现使用状态改变时继续读取旧代码。

## 时间与生命周期

- 桌面应用进程运行时按计划检查，休眠后在恢复时补查；应用退出后不承诺执行。
- Android/iOS 复用宿主现有系统唤醒任务，平台决定实际执行时间，频率不是精确定时保证。该功能无需插件的后台任务权限，也不会为更新单独启动前台常驻服务。
- 手机系统唤醒只检查并准备包，不修改安装索引。一次唤醒的更新时间预算为 22 秒，未完成的工作下次重试。
- 安装只在前台、插件没有打开的页面或可见卡片、没有交互弹层/未完成脚本事件/正在运行的任务时执行。保留的底栏页面需要关闭或下次启动才会替换。
- 原插件后台任务与更新共用唤醒注册；关闭其中一项不会取消另一项仍需要的系统任务。

计划、检查时间、重试时间和候选包持久化在 `metaverse_plugins/updates.sqlite`。事务租约避免多个引擎重复检查；进程退出留下的租约在 5 分钟后过期。失败从 15 分钟起指数退避，最多 6 小时，并遵守市场服务返回的冷却时间。回到前台不会无条件重新下载。

## 状态与验证

设置页展示上次/下次检查、待空闲安装、待确认、宿主不兼容及失败重试状态。“查看更新”进入市场详情和现有安装审阅流程。后台更新日志先保存在更新库，回前台后归档。更新日志标为 `plugin_update`，包含插件 ID、原版本、目标版本及结果，归属宿主框架。

针对性测试：`metaverse_auto_update_test.dart` 覆盖真实前台定时器、跨引擎租约、退避、校验失败、权限变化、卸载/手动更新竞态以及回滚；`metaverse_update_ui_test.dart` 覆盖小屏、大字、明暗主题和频率/单插件开关交互。
