# 士多与服务卡片体验核对

本次核对原生买家流程与交互（2026-11-19），商城业务保持在独立插件中。

| 使用流程 | 核对范围 | 落点 |
| --- | --- | --- |
| 服务入口 | 整张卡片进入默认页，卡片下方可定义统计等内容，菜单保持独立 | 清单 `card.page`、通用统计组件、独立插件 |
| 页面外壳 | 标题不重复服务名与第三方标签；权限从插件管理进入，使用时仍可申请 | 宿主页面 |
| 商品列表 | 搜索、横向分类、排序、库存与价格筛选、分页、折扣、类型与卖家 | 固定工具区、金额与内容组件、士多插件 |
| 商品详情 | 图片查看、格式化说明、卖家入口、库存销量、限购/信任/测试限制 | 受控图片与富文本组件、士多插件 |
| 下单 | 数量、核价、选券、金额变化确认、幂等恢复、自动打开订单 | 通用数量组件、士多插件 |
| 订单 | 状态分类、缩略图、支付截止、金额明细、时间、动态、交付查看/复制、重新兑换 | 通用详情与时间线、士多插件 |
| 优惠券 | 适用范围、有效期、占用/使用订单、实际优惠、不可用原因 | 士多插件 |
| 账号与消息 | 待付款、待发货、券、售后及未读统计；系统消息筛选、分页和显式已读；消息中的商品、券、订单原生跳转 | 士多插件 |
| 已有扩展 | 原生支付、收藏、领取优惠券、评论、售后 | 保持并接入统一页面布局 |

敏感操作仅以模拟服务验证；不使用真实账号支付、退款或发布评论。界面检查覆盖小屏、大字、明暗主题、加载/空态/失败。公共组件同步开发中心、参数契约与独立 SDK。

本轮覆盖原生买家功能。卖家后台、求购会话仍通过网站使用；插件保留网站消息中心入口，系统消息已有原生页面。网页与插件凭证分区，网页可能需要自行登录，插件不会把令牌注入网页。论坛域名上的卖家头像若未被宿主登记为可信头像，会显示昵称首字，普通公网头像仍走受控图片出口。

本轮版本：士多 2.2.0、动态订阅 1.2.0、SDK/CLI 0.6.0。需要支持 cardNavigation / contentPresentation 的新宿主。通过原安装来源更新插件以保留状态与数据。


### 实时消息（2.3.0）

买家插件接入 `/api/shop/notifications/stream`，由通用 `eventStreams` 能力传输。实例共享连接，摘要更新未读统计，系统消息变更静默更新第一页；已分页的列表提示手动刷新。断线补查摘要和可见消息，隐藏暂停，失效会话停止重试；遵守服务端连接数限制的冷却提示。不把服务端消息当作付款成功依据，订单仍回查权威状态。

SDK 0.7.0 增加流接口、事件类型与应用内动态演示；不增加常驻权限按钮或新的通知授权弹层。没有用户账号实测，未执行付款、退款或标记已读。
