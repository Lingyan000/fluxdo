# 头像请求尺寸

头像模板统一通过 AvatarUrl.resolve 替换 {size}。size 表示请求像素，不是逻辑显示尺寸；现有调用已经选定像素，不再重复乘 DPR。显示组件需要调整清晰度时，应先换算一次再传入。

档位来自首页预加载 siteSettings.avatar_sizes，更新、测试注入及清空时同步更新。去重排序并过滤服务端不支持的范围，选不小于目标的最小档位，最大值封顶；没有有效配置时回退 Discourse 默认 24/48/72/96/144/288。不额外请求站点配置。

覆盖模型、聊天/嵌套/Boost 等直接模板入口及通知头像。通知缓存模板而非已选档 URL，避免配置更新后继续使用旧尺寸；缓存容量不变。实际 URL、动画原件、CDN 路径解析、下载并发和图片缓存策略保持原契约。

依据 Discourse avatar-utils.js 的 getRawAvatarSize 与 user_avatars_controller.rb：外部存储对非标准尺寸跳最近档，而网页端预先向上选档保证清晰度。不能把避免尺寸跳转理解成消除所有 302，头像更新和存储跳转仍可能发生。

验证：test/utils/avatar_url_test.dart 覆盖日志中的非标准尺寸、自定义站点档位、非法配置、预加载更新/清空、真实模型入口和实际 URL 保留。真机验收应比较相同列表中的 302 次数与图片耗时，不改变 DoH/代理及缓存条件。
