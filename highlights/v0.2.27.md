这一版重点在两处:长按、放大、返回这些动作的观感重做了一轮,外观能改的地方多了不少。另外新增加解密工具箱和话题目录。

### 🎨 外观

- 主题色新增六套配色:默认、湖蓝、海洋、樱花、春、秋。
- 「中性」开关:界面表面不再被主题色染色。
- 「纯黑」开关:深色模式下用真黑背景,AMOLED 屏更省电。
- 可以设置背景图片,配合「透明」表面质感透出背景,遮罩浓淡和模糊程度可调。
- 底栏新增三个开关:只留图标、悬浮胶囊、毛玻璃。

### 🔍 长按预览

- 长按话题卡片的预览换了样式,打开和收起都比以前连贯。
- 预览里的分类和标签可以直接点进去。
- 预览打开更快,大多数时候不用等加载。
- 搜索结果、话题内搜索的卡片也能长按预览了。

### 🖼️ 图片

- 长按正文图片会浮起预览和一排操作。
- 放大之后直接返回,不再中途跳一下才回到原位。
- 修了返回时的黑闪,以及轮播图、聊天图片被裁切。

### 🔐 加解密工具箱

- 选中疑似密文的内容,工具栏出现「解密」,面板自动识别算法,解出来可复制或引用回复。
- 编辑器里选中内容点钥匙按钮即加密插回,富文本模式在「+」菜单。
- 算法覆盖 AES、3DES、ChaCha20 等对称算法,Base64/Hex/ROT13 编码,MD5/SHA/SM3 哈希,RSA,以及凯撒、维吉尼亚、栅栏、摩斯。与 openssl 命令行生成的密文互通。
- 密文识别认 Base32、折行 Base64、带冒号或短横的 Hex;可选记住密码,功能设置里一键清除。

### 📑 话题目录

- 长帖会生成目录,宽屏在右侧,窄屏收在右下角按钮里。
- 滚动时当前小节自动高亮,点一下跳过去。
- Markdown 工具栏新增「插入目录」。

### 🛡️ 过盾与网络

- 修了验证通过后又被反复要求验证。
- 「切换兼容模式」的询问多了第三个选择「关闭自动验证」,不想承担兼容模式的性能代价可以关掉自动过盾,改成撞盾时手动点。
- 修了过盾之后阅读时长不再上报。
- 被限流时的等待时间更合理,发帖也不会因为重试而重复提交。

### ✏️ 编辑与阅读

- 修了帖子里有行内剧透时富文本模式打不开。
- 长帖的正文字号设置现在整篇生效。
- 代码块只选一部分复制,不会再被硬套整块的语言标记。
- 剧透点开后不会再被二次点击盖回去。
- 修了表格里放图片崩溃;居中段落里的列表和表格现在跟着居中。
- 底部弹框支持预测式返回,全 app 七十多处一起生效。
- 话题里可以只看某一位用户的发言,入口在用户卡片和头像菜单。

### 🛠️ 其他修复

- 阅读进度条不再偶发跳顶或跳底,最后一楼也不会被错标已读。
- 修了聊天里点置顶消息横幅第一次没反应、点完丢滚动位置和草稿。
- 修了树形视图下从解决方案横幅、话题内搜索、编辑历史跳楼层无法定位。
- 修了退出登录卡在「正在退出…」,以及自定义过底栏后重新登录跳到第二个标签。
- 修了投票、政策操作完滚出去再滚回来状态回退。
- 修了 HyperOS 4 小窗下界面空白只剩底栏,以及资料页横屏时头部内容叠印。
- 设置搜索能正确跳转到靠页尾的条目;功能设置重新分了六组。
- 表情包加载失败能看到具体原因;更新检查可配置 GitHub 反代前缀。
