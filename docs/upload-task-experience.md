# 编辑器上传任务体验

每个 Markdown、富文本、聊天输入条独立持有 UploadTaskController；取消令牌贯穿实际上传请求。服务端已完成但正文转换失败时保留 UploadResult，重试仅转换/插入，不重复上传。

## 展示

- 工具按钮保持原图标，任务面板位于工具栏上方，显示预览、阶段、失败重试及取消/移除。
- 分片 PUT 显示去重字节进度；重试高水位不重复累计。分片传完后进入服务端处理状态，不提前宣称成功。
- 普通 WebView 上传不能获得真实网络字节进度，使用不定进度，不把 Dart→JS 搬运量作为网络进度。
- 聊天完成后保留附件预览，发送才清除；失败附件阻止发送，但不永久显示上传转圈。
- 音视频先完成已有模式选择/本地压缩流程，再入统一网络上传任务；重试使用已处理文件。

## 正文与生命周期

Markdown 不插占位字符串；使用内存位置锚点，用户编辑时调整位置，乱序完成按注册顺序插入且不主动聚焦。大范围整体替换会将锚点归并到变更起点。多图采用逐图插入，不再自动包裹 grid，避免失败重试改写用户正文。

富文本临时卡片由空 ParagraphNode 岛承载，任务路径不进入文档；导出时过滤占位。折叠选区的文本块会在光标处拆段；非折叠选区在当前块之后插入卡片，不覆盖选中文本。删除/撤销取消关联任务；正式内容替换后清理该占位的历史引用，避免 undo 恢复无主空卡。图片组追加与占位移除合并为一次替换事务。

发布入口（创建话题、编辑话题、回复）和编辑器模式切换检查未完成/失败任务。关闭编辑器取消请求，临时任务不持久化，也不支持重启续传。
