# 玻璃材质的场景分级

全局玻璃开关及 `auto/basic/full` 仍控制效果能力；场景配方决定背景隔离强度，不新增用户设置。

| 场景 | 配方 | 主模糊 σ（物理像素） | 底色 alpha（浅/深） | 入口 |
| --- | --- | ---: | ---: | --- |
| 导航 | `navigation` | 14 | .32 / .32 | 悬浮底栏 |
| 工具条 | `toolbar` | 32 | .56 / .70 | 收起的编辑工具岛、块旁紧凑操作条 |
| 菜单 | `menu` | 48 | .74 / .80 | 对象菜单、斜杠/添加块选择器 |
| 内容面板 | `sheet` | 64 | .80 / .86 | 手机和桌面展开的编辑工具岛 |
| 聚焦确认材质 | `dialog` | 80 | .86 / .90 | 可供玻璃确认卡片使用 |

深色工具及内容表面额外加厚底色，以抑制亮背景对浅色文字的干扰。菜单和面板同步降低折射、色散及磨砂噪点。可读性由模糊和底色共同提供，避免仅增大 sigma 仍透出大块背景色。基础档和完整档使用相同配方；基础档底色再加厚 .08。关闭玻璃或启用高对比度时保持实色，不改变布局、输入内容和焦点。

工具岛打开面板时增强隔离，关闭动画结束后恢复工具条配方。导航保留原有通透感。

## 模态背景

路由背景模糊与局部玻璃分开处理，继续遵守 `dialogBlur` 偏好、调用方的 `blur: false` 与自定义遮罩色：

- 底部面板：sigma 18 逻辑像素，浅色遮罩 .12，深色 .24，保留更多页面上下文。
- 对话框：sigma 25 逻辑像素，浅色遮罩 .20，深色 .32，突出前景决策内容。
- 其他直接调用旧模糊工具的入口保持原默认行为；回复编辑器等主动关闭全屏模糊的入口仍关闭。

局部玻璃的物理像素 sigma 按当前视图 DPR 换算，全屏路由使用逻辑像素，两者不混用。

## 验证

`glass_readability_test.dart` 在明暗主题、DPR 1/3、基础与完整材质下测量同一对比背景透过玻璃后的亮度波动，验证隔离逐级增强；宽色带避免把最强档之间的差别误判为像素量化噪声。工具条及内容表面还验证主题正文色与透出的背景达到 4.5:1；该检查仅针对测试背景和 onSurface 正文色，并不替代所有产品文案的对比度审查。完整档必须实际运行两层 GPU 滤镜。测试还检查切换材质保留输入和焦点。

`modal_blur_scene_test.dart` 验证真实路由的滤镜、遮罩及模糊关闭行为；现有玻璃设置、几何和编辑器交互测试覆盖全局开关、高对比度与布局稳定性。
