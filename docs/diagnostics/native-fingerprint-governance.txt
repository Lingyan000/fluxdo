结论
最终原生任务全部通过所列字段和传输场景的比较，Linux WPE 的后端差异单独保留为失败。
这不是“所有平台所有指纹完全相同”，不是完整 Flutter 应用或 CF 挑战成功的证明。

运行时与证据边界
Android：API 35 / Android 15 模拟器 AE3A.240806.043；WebView 124.0.6367.219。
  原生 UA、按应用规则处理后的 UA 两种配置；浏览器在 Android，Core 在 Linux 宿主。
Windows：Windows NT 10.0.20348.0；WebView2 131.0.2903.86，UA Chrome/131 Edg/131。
  原生 WinForms WebView2 宿主和 Windows Core。不能称为当前最新 WebView2 版本。
macOS：15.8.2 (24H232)，WKWebView；原生 UA 与应用 UA 两种配置；Core 在 macOS。
iOS 26.2：模拟器 23C54，原生 WKWebView，原生 UA 与应用 UA 两种配置；Core 在 macOS。
iOS 15.5：模拟器 19F70，原生 WKWebView，原生 UA 与应用 UA 两种配置；Core 在 macOS。
  iOS 15.0 原生运行仍受当前 macOS 宿主限制，未将 15.5 结果外推到全部 15.x。
Linux：Playwright headless WPE WebKit 26.5；实际仓库 Linux 插件也是 WPE 后端家族，
  但版本和编译条件不代表用户安装的所有发行版本。真实复测仍存在 BoringSSL 能力差异。

H2 初始帧、伪头顺序、默认 fetch HEADERS 优先级、Accept-Encoding、低熵 Client Hints、
Fetch Metadata 存在性，以及连接复用、连接池重置、四请求冷并发、磁盘缓存恢复、超时恢复。
每配置 5 个传输场景；三个工作流共 11 个 case（macOS 控制组重复），55 个场景通过。
去重后是 9 种原生配置、45 个场景，不含 Linux WPE。磁盘恢复测试不等同 TLS 会话恢复。

- Windows 任务 43677450512 的采集完成，写报告遇到 cp1252 编码错误；统一 UTF-8 后原生任务通过。

  改为完全独立、无网络的 HelloSink 配置，生产证书校验保持平台校验；新目录复跑 15/15 通过。

  status.tls_capabilities.status 为 backend_mismatch，采样 ready 不是完整一致性标记。
