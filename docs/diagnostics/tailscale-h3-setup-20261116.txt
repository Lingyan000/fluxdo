Tailscale 一次性设置
1. 在 DNS 页面启用 MagicDNS、HTTPS Certificates。
   https://console.tailscale.com/admin/dns
   发证会在公开证书透明日志中出现节点域名；预检采用中性的 fluxdo-h3-preflight 主机名。
2. 为 CI 创建 tag:fluxdo-ci，仅由管理员管理。
   如果使用策略文件，在现有 tagOwners 中增加该项，不覆盖原有策略：
   "tag:fluxdo-ci": ["autogroup:admin"]
3. 进入 Trust credentials，选择 Credential → OpenID Connect：
   https://console.tailscale.com/admin/settings/trust-credentials
   Issuer: GitHub Actions；自定义时填 https://token.actions.githubusercontent.com
   Subject:
   repo:Lingyan000/fluxdo:ref:refs/heads/diagnostics/tailscale-h3-preflight-20261116
   权限仅 Auth Keys → Write，选择 tag:fluxdo-ci。
   可进一步增加 custom claim workflow_ref：
   Lingyan000/fluxdo/.github/workflows/tailscale-h3-preflight.yaml@refs/heads/diagnostics/tailscale-h3-preflight-20261116
4. 返回生成的 Client ID 和 Audience。它们不是秘密；不要提供 OAuth secret、auth key 或 JWT。
   填入 tool/native_fingerprint/tailscale-oidc.json 后，才推送专用预检分支。
   当前文件留空会在加入网络前失败，不会误报已完成连接。

实现和额度边界
- 官方 Tailscale Action v4 固定到 064b10558093f38325e838ddea35486bdc6b1d5c，客户端 1.104.5。
- 使用 GitHub 临时 OIDC 令牌，只准入上述仓库/分支；无 pull_request 触发。
- 仅上传 result.json；节点状态全量 JSON、证书私钥、ACME 状态不上传、不缓存。
- Action 的 post 步骤退出临时节点，临时目录删除证书；取消/平台故障仍以云端实际清理结果为准。
- 配置和本地证书负对照不消耗 Tailscale 额度；真实发证仅在配置好后执行一次。
- 后续原始 QUIC 由本项目采样程序终止，不使用 Tailscale Serve/Funnel 的 HTTPS 终止替代。
  本阶段不向正式应用加入 VPN 依赖，也不证明 Windows 业务/独立 profile 策略相同。
