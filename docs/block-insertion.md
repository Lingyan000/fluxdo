# 块插入事务与异步位置

对照本地 Discourse `static/prosemirror/lib/text-manipulation.js`：普通块插入以replaceSelection单事务完成；上传按占位身份替换；blockquote使用wrap/lift，而非模板拼接。

本轮将EditorState.pasteBlocks的选区删除和片段插入放到隔离草稿状态计算，再一次提交，避免先删后插产生两步撤销和中间文档通知。保留原片段重编号、容器和尾段逻辑。

InsertionBookmark追踪块ID与块内文字差异。目标被删除、选区内文字被修改时失效，不覆盖新输入。异步转换期间用户移动光标时，插入后尽力映射并保留其当前选区。连续大范围替换和结构转换并非ProseMirror transaction mapping的完整等价实现，无法映射时保守放弃。

验证：内核test/editor 905项通过；应用插入锚点、选区单事务与撤销等8项通过。

已补齐文件、音视频、语音和模板打开弹框前的位置保存；表格/代码块插入后请求进入编辑（用户已移开光标则不抢焦点）。表格首格聚焦6项专项测试通过；引用中插入保留前后文字及容器并一次撤销的测试通过。链接、投票、加密等其他专用弹框尚未全部迁移，复杂跨块结构编辑期间采用保守取消，不宣称与ProseMirror完整事务映射等价。
