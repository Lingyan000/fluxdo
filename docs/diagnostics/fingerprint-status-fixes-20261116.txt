1. 状态同步
- TLS/H2 templateReady 仍提前通知，首次业务请求不等待可选 H3。
- calibrationRevision 在当前代采样任务完成时通知，包括成功、失败、不可读及探针异常。
- NetworkSettingsService 收到完成通知后重新读取核心状态。
- reset 或换核心使旧代失效；旧任务完成不能触发新核心的刷新。
- 导出直接通过只读 FFI 快照读取，不再依赖上述业务状态缓存；导出失败不发布 stopped。

2. 诊断准确性
- coreStatusRead: live / status_unavailable / status_read_failed / status_invalid。
- h3CalibrationState: unknown / notReady / sampled；缺失或损坏就绪字段为 unknown。
- 原生明确未就绪时保留 error/reason；没有原因写 reason_unavailable，不写 none。
- 读取失败时核心运行状态、系统代理及模板字段为 null；没有应用代理时出口记 unknown。
  仍保留已知的应用代理配置；proxySource 表示配置来源，不证明目标请求的实际 PAC 路由。
- 旧核心缺少字段也保持未知，不由默认值编造 auto、直连或 H3 失败。
- Rust verification_scope 明确本地两 origin 校准、逐连接协议日志与 CF 接受性。
  not_verified 中歧义项 quic_h3 改为 quic_h3_end_to_end；本地样本就绪仍由 h3 表达。
- 未改变 CSRF/Cookie/Origin/Referer 业务策略、证书信任、网络选路或生产 H3 回放。
  改动在共用 Dart 与 Rust 层，适用于 Android/iOS/macOS/Windows/Linux。
